# SHIRAN Bridal Studio · אב טיפוס חזון

הכלה רואה את השמלה עליה, רק אחרי שהסכימה.

יועצת בסלון פותחת סשן, הכלה מסמנת הסכמה מפורשת, מצלמים (או בוחרים דמות הדגמה), בוחרים דגם מהקטלוג המאושר לסלון, ורואים המחשה מסומנת.
ההזמנה עוברת לאישור בעלת הסלון.

נתוני הדגמה בלבד. אין שרת, אין AI בתשלום, ואין שליחת תמונות.

```bash
npm install
npm run dev
```
